# BS13B Responsibility Decision Register

Baseline: `f4370be` (BS13A), branch `bdm-stage2-bs13b-responsibility-delegation-convergence`.
All six kinds were registered but had no live end-to-end Staff caller. The existing
Responsibility registry is the canonical authority; legacy rows remain readable.

| Responsibility | Definition / roles / modes / cost | Current owner and nearby path | UI / persistence / duplication finding | Decision | Future owner / rationale |

No new Staff-to-domain path is approved in BS13B. Deferred kinds remain documented and
registered for compatibility, but all six kinds are inactive for new assignment, resolver
execution, workload, default world enrichment, and the Staff Responsibilities UI. Existing
persisted rows are retained inertly rather than migrated or deleted.
