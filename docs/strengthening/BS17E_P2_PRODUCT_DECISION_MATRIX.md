# BS17E-P2 · Product decision matrix

**Nine P2 principles are ratified** in [BS17E-P2 V1](BS17E_P2_V1_APPROVED_POLICY.md): SIM-01–SIM-05 and GOV-01–GOV-04. Their detailed policies remain pending as marked below. These decisions do not approve prices, formulas, calibration, a supplier model, organization charts, or grants. E-P03 and E-P05–E-P10 remain `PROPOSED_NOT_APPROVED`.

## Coherent new-game maintenance trace — current vs proposed

| Stage | Current evidence at P2 baseline | Required future behavior / blocker |
|---|---|---|
| Physical need | Facilities can represent a need, source scope, and physical work; it has no price. | Reuse the canonical need/action ID; scope evidence must be sufficient for an offer. |
| Request / cost | No Facility cost offer source or generator found. Generic Finance source engines exist. | E-P02-SIM must approve the source and model. Until then, report `UNKNOWN_COST` where no documented cost exists. |
| Institutional decision | Governance types, bodies, grants, rights and events exist, but no Facilities grant bootstrap or operational command was found. | E-P04 mapping and bootstrap must produce/resolve valid rights; otherwise `INSTITUTIONAL_AUTHORITY_UNVERIFIED`. |
| Finance authorization / contract | Finance canonical authority exists; BS16M is PASS in the read-only current Finance roadmap, but BS16N remains the final certification. Facilities E-P03/E-P05 remain unapproved and the CFI7 baseline lacks a complete pre-work-to-settlement route. | Require BS16 global PASS, integration, and approved gate/obligation policy. No binding contract or work can be claimed LIVE. |
| Physical completion / recognition / payment | Facilities owns physical work; Finance owns recognition and settlement. They are separate authorities. | Connect through approved adapter; completion never implies recognized cost or cash paid. |

| Scenario | Expected proposal behavior |
|---|---|
| Club lacks valid price inputs | `UNKNOWN_COST`; preserve physical need, create no commitment. |
| Organization lacks grants or profile | `INSTITUTIONAL_AUTHORITY_UNVERIFIED`; no fallback manager approval. |
| Offer is expired | It cannot be selected/contracted; issue a distinct new request only under approved validity policy. |
| Currency is unknown/incompatible | Finance rejects/block with its canonical reason; no country inference or implicit FX. |
| Proposal rejected/vetoed | Preserve Governance event; do not reserve/commit or start economic work. |
| Replacement has mixed scope | Require legitimate scope breakdown; otherwise leave classification and price unresolved. |
| Capital project Facility does not yet exist | Use an approved stable project subject/reference if supported; do not invent a Facility ID or attach rights by ownership inference. |
| Approver changes after proposal | Preserve proposal history; resolve the actor/grant effective on each later event; block or route per approved policy. |
| AI performs the same action | Same commands, appointments, grants, Finance gates and denials as user; no AI-only authority. |
