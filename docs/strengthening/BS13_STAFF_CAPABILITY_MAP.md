# BS13 Staff Capability Map

Status is about an end-to-end Staff-backed flow. A role or responsibility declaration alone is not a connected capability. See [the authority map](BS13_STAFF_AUTHORITY_MAP.md) for canonical ownership and [the integration matrix](BS13_STAFF_INTEGRATION_MATRIX.md) for traced source-to-consequence flows.
