# CAREER-F0B · Revisión de experiencia

## Courtside

`CourtsideTacticsPanels` ya presenta el próximo rival, el informe de oposición, la calidad del scouting y las señales disponibles. F0B añade una acción visible `ACEPTAR RECOMENDACIÓN` que invoca el boundary canónico y guarda el override del próximo partido. El botón existente `APLICAR AL PARTIDO` continúa permitiendo que el entrenador modifique el plan.

## Staff

`StaffWorkspace` reutiliza las responsabilidades existentes y permite pasar entre `userControlled`, `delegated` y `advisory` según el registro canónico. No se añade un panel paralelo ni un calendario duplicado.

## Datos no jugables

CoachCareer mantiene sus valores de demostración inequívocamente marcados como `MOCK`; F0B no los usa para simular decisiones de entrenamiento, scouting, tácticas o partidos.
