BDM GAME SVG ICONS

Este paquete contiene los iconos separados y listos para adaptar al juego.

Contenido:
- svg/: archivos SVG individuales, uno por icono
- png/20, png/28, png/48, png/64: fallback PNG
- manifest.json: mapeo técnico

Total:
- 56 SVG extraídos del catálogo final
- 1 SVG adicional para el logo BDM
- 57 assets SVG individuales en total

Nota:
Los SVG preservan exactamente el aspecto del icono porque encapsulan el asset transparente original dentro de un viewBox responsive.
