# Milestone 017 - Derived player boxscore v1

## Goal

Derive a minimal individual boxscore from the player-attributed MatchEvents without persisting duplicated statistics.

## New projection

Create a pure Engine projection such as:

`calculateMatchPlayerStats(simulation): readonly PlayerMatchStats[]`

with at least:

- playerId
- points
- fieldGoalsMade
- fieldGoalsAttempted
- turnovers

Return rows for all ten players in `simulation.lineups`, including players with zeroes.

Current semantics:
- `shotMade` with 2 or 3 points: points += points, FGM += 1, FGA += 1
- `shotMade` with 1 point, if still possible in the current engine: points += 1 but do not count it as a field goal
- `shotMissed`: FGA += 1
- `turnover`: TO += 1
- structural events do nothing

Do not persist stats to Game, Player, Team or GameWorld.

## Partial/revealed stats

Provide a pure way to calculate the same stats from only the events revealed so far in MatchViewer. It may be:
- an optional event limit argument, or
- a separate helper operating on a revealed-event slice.

It must not expose future events.

## Viewer

Add a compact in-game stats panel using only revealed events.

Minimum columns:
- Player
- PTS
- FG (display `FGM/FGA`)
- TO

Show both teams' five starters. Keep layout practical rather than redesigning the entire screen.

At final whistle, the panel must match `calculateMatchPlayerStats(simulation)` over the complete simulation.

## Tests

Add controlled-event tests for:
- made 2
- made 3
- made 1 semantics if supported
- miss
- turnover
- zero-stat players still included
- exactly ten rows for normal simulation
- complete event-derived totals
- partial stats exclude later events
- final partial/full equivalence
- no mutation

Keep existing match determinism and Viewer controls green.

## Architecture

- stats are Engine projections
- UI renders projections
- Zustand does not become the stats engine
- no persisted boxscore yet

Update `docs/ARCHITECTURE.md`.

## Do not implement

- rebounds
- assists
- steals
- blocks
- fouls
- minutes
- plus/minus
- season/career stats
- substitutions
