# BG8F — Final Integration & Certification

BG8F certifies Board / Club Governance V2 as one deterministic architecture
from BG1 through BG8E. It adds no gameplay subsystem. The certification suite
covers the material end-to-end chains:

- BG8D conflict → BG8E regulatory order/remediation → BG8B forced divestment → BG8D reassessment;
- BG8C investor interest/capital raise/proposal/execution → canonical dilution → BG8D assessment;
- BG8B secondary sale preview → execution → matching BG8D assessment;
- BG8E succession while preserving historical Organization and ownership facts.

The audit retains the established boundaries: Person/Player/Staff identity,
Organization/Team/GovernanceInstitution separation, explicit Control,
Governance authority distinct from ownership, supporter systems distinct from
ownership, and derived conflict assessments are not persisted as truth.

The remaining `organizationIdForTeam` production references are explicit
legacy compatibility boundaries: V1 knowledge migration and legacy `Team`
input normalization. Canonical runtime and all BG8 ownership/regulatory paths
use `team.organizationId`.
